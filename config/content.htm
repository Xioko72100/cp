w3: 什麼是 git, GitHub, gist 與 cmsimde? 如何使用這些工具？為什麼要使用這些工具？ (動態模擬)

git是一個版本控制控管的東西，連接github就可以把檔案推送上去，可以方便多人協作不會被覆蓋，github上還有超多別人做的開源軟體，可以抓下來修改或是參考，東抓西抓東拼西湊，也可以用出東西來。gist在github上就是可以放小段程式，不用一定要倉儲。cmsimde是以python跟flask編寫的管理系統，透過近端的 Python 環境執行 cms 指令來啟動編輯介面或產生靜態網頁。使用這些工具可以增加效率。

w7: Brython 是什麼？如何在瀏覽器配置 Brython 環境？ Brython 能做什麼？ (Brython, Examples)

Brython是一個用javascript編寫的東西，他把python及時轉換成js給網頁，讓瀏覽器可以直接透過python執行，配置方法就是在html的<head>標籤裡面加入

<script type="text/javascript" src="https://cdnjs.cloudflare.com/ajax/libs/brython/3.10.7/brython.min.js"></script>
<script type="text/javascript" src="https://cdnjs.cloudflare.com/ajax/libs/brython/3.10.7/brython_stdlib.min.js"></script>

然後在 <body> 標籤中加入 onload="brython()"，告訴瀏覽器網頁載入後啟動 Brython 引擎。使用 <script type="text/python"> 標籤來寫 Python。

Brython可以抓取 id、更改 CSS 樣式、動態新增 HTML 標籤。綁定滑鼠點擊、鍵盤輸入、視窗滾動等事件。可以使用 math, datetime, json, 等大部分 Python 標準庫。 支援 HTML5 canvas 繪圖，適合製作簡單的網頁遊戲或數據視覺化。就像老師brython分頁裡的機器人模型。Brython 可以呼叫現有的 JavaScript 函式庫。

w10: 如何在瀏覽器中模擬機器人作動？ (機器人作動)

老師使用的方法是使用 Brython + HTML5 Canvas，如果要3D的就要用到Three.js。利用 Python 邏輯計算座標，再透過 browser.timer 定時刷新畫布。把要建立的指令都打出來就好。
